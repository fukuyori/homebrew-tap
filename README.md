# Homebrew tap for tfx

This tap distributes [tfx](https://github.com/fukuyori/tfx), a keyboard-first
macOS file manager with a terminal-inspired interface.

## Install

```sh
brew install --cask fukuyori/tap/tfx
```

The cask installs `tfx.app` in `/Applications` and provides the `tfx` command.

```sh
tfx --version
tfx .
```

tfx requires Apple Silicon and macOS 15 or later.
